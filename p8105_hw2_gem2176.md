This data set describes the NYC subway station entrances and exits. For
each entrance and exit, the data set describes the line, the station,
the latitude and longitude of the station, the routes that pass through
the station (up to 11 routes), whether entry is allows, whether the
entry is with or without vending, the type of entrance, and whether the
entrance is ADA compliant. Thus far, the data has been cleaned to only
include variables of interest and to transform the entry variable from a
character variable to a vector variable. The current data frame has 19
columns and 1868 rows. The data is not tidy because the route number and
name are in wide format instead of long format.
